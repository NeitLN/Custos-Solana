# Font SolBonus demo

Các tệp Be Vietnam Pro được sao chép nguyên bản từ `apps/demo-wallet/public/landing/fonts/` trong cùng repository; gồm weight 400/600/700 và subset Latin/Vietnamese.

Nguồn: Google Fonts, họ Be Vietnam Pro. Giấy phép SIL Open Font License 1.1. Xem hồ sơ nguồn tại `apps/demo-wallet/public/landing/asset-sources.md`.

Không tải font từ dịch vụ bên ngoài khi chạy trang. Vite ánh xạ asset theo base riêng của app attack khi build.
